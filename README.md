# 스톤브릿지 홍보글 에이전트

동네 카페 **스톤브릿지** 사장님이 사진 몇 장과 한 줄 메모를 올리면, 사장님 말투로 **네이버 블로그 · 인스타그램 · 당근 · 네이버 플레이스** 글 초안을 한 번에 만들어 주는 에이전트입니다.
노마드코더 AX School "Put AI to Work" 챌린지 과제로 만들고 있습니다.

## 누구를 위한, 어떤 업무인가

- **클라이언트:** 구리시에서 카페 스톤브릿지를 운영하는 사장님 (지인, 실제 클라이언트). 알바생 4명과 매장을 운영하고, 케이터링 사업 "스톤테이블"을 새로 시작했습니다.
- **대신하는 업무:** 홍보글 쓰기. 사장님은 한 달에 1~2번, 같은 내용을 네 채널에 말투만 바꿔 직접 올립니다. 블로그 글 하나에 1~2시간이 걸리고, 사진 고르기가 가장 오래 걸립니다.
- **왜 이 업무인가:** 사장님 인터뷰에서 "업무 하나가 사라진다면?"과 "미루게 되는 일은?" 두 질문에 모두 **"글 쓰는 거"**라고 답했습니다. 예전에 ChatGPT·Claude로 써 봤지만 **말투가 AI 같아서** 쓰지 않게 됐습니다.

> 처음 기획안(Day 1)은 케이터링 견적 에이전트였습니다. 이후 사장님과 업무 전체를 인터뷰해 보니 견적보다 홍보글이 훨씬 급하고 자주 하는 일이라 대상을 바꿨습니다. 견적 에이전트는 다음 순서로 미뤘습니다.

## 어떻게 동작하나

1. 사장님이 휴대폰으로 웹 화면을 열고, 비밀번호로 들어가 사진(0~8장)과 메모를 올립니다. (예: "구리 관공서 마카롱 8구 70세트 단체 주문")
2. 에이전트(Claude Opus 5.5)가 사장님이 직접 쓴 블로그 글과 이미 확정한 글을 말투 예시로 삼아, 블로그·인스타·당근·플레이스 초안을 한 번에 만듭니다. 약 30초~1분이 걸리고, 화면을 닫아도 계속 만듭니다.
3. 가격표, 배송 정책, 주소·영업시간 꼬리말은 AI가 쓰지 않고 **설정 화면에 저장해 둔 문구를 코드가 그대로 붙입니다.** 틀린 가격이 나갈 수 없게 하려는 것입니다.
4. 사장님이 채널별로 고치고(자동 저장), **복사 버튼**으로 각 채널에 올립니다. 마음에 안 들면 한 줄 지시("좀 더 짧게")로 그 채널만 다시 쓰게 합니다.
5. 마음에 들면 **확정**합니다. 확정한 글은 다음 글의 말투 예시가 됩니다.

사장님이 쓰는 에이전트는 Cloudflare Workers에서 항상 켜져 있는 웹 프로그램이고, Claude API를 호출합니다.

## 진행 상황

### 지금 되는 것
- 휴대폰 웹에서 사진(0~8장) + 메모 → 블로그·인스타·당근·플레이스 초안을 한 번에 (Claude Opus 5.5, 약 30초~1분, 회당 약 $0.1)
- 채널별 고치기(자동 저장), 복사, 다시 쓰기(한 줄 지시), 확정
- 꼬리말·가격표는 AI가 아니라 코드가 붙임
- 메모에 없는 숫자("세 세트" 같은 한글 숫자 포함)와 (개인 고객 주문이면) 이름은 노란색으로 표시하고, 메모에 없는 주문 방법·예약·할인 같은 운영 방식은 쓰지 않게 함 (지어내기 방지)
- 확정한 글이 다음 글의 말투 예시가 됨
- 사장님 블로그 글 50개를 말투 예시로 사용 (글 원문은 저장소에 넣지 않음)
- 화면을 닫아도 생성이 계속됨 (Cloudflare Workflows)
- 사진은 서명된 10분짜리 주소로만 AI에 전달
- 사장님 인터뷰 (업무 25개 체크, 질문 47개 답변) 와 설계 문서: [docs/superpowers/specs/2026-11-08-promo-agent-design.md](docs/superpowers/specs/2026-11-08-promo-agent-design.md)

### 아직 안 되는 것
- 카톡 알림: 카카오 "나에게 보내기"로 가능하다는 것까지 확인했습니다 (권한 신청 없음). 콘솔 설정 순서: [docs/kakao-setup.md](docs/kakao-setup.md)
- 사진 자동 고르기: 사진 묶음을 받으면 AI가 먼저 고르는 기능은 다음 버전입니다.
- 자동 게시: 네이버 블로그·당근·플레이스는 공식 글쓰기 API가 없어 **복사 버튼**으로 올립니다. 인스타그램은 공식 API가 있어 다음 버전 후보입니다.
- 스톤테이블(케이터링) 브랜드 분리: 지금은 스톤브릿지 한 가게 기준입니다.

## 개발

스택: React Router 8 + Cloudflare Workers (Workflows, D1, R2) + Drizzle + Claude API (`@anthropic-ai/sdk`).

```bash
# Node 22.22 이상 필요
npm install
cp .dev.vars.example .dev.vars   # 값을 채웁니다
npm run dev                      # http://localhost:5173
npm test                         # vitest
```

`.dev.vars`에 들어가는 이름 (값은 저장소에 넣지 않고, 배포 때는 `wrangler secret put`으로 Cloudflare secret에 넣습니다):

- `ANTHROPIC_API_KEY`
- `SESSION_SECRET`
- `OWNER_INITIAL_PASSWORD`
- `IMAGE_URL_SECRET`
- `PUBLIC_ORIGIN` (로컬은 `http://localhost:5173`)
- `FAKE_CLAUDE=1` (선택): Claude를 부르지 않고 가짜 초안을 돌려줍니다. API 키 없이 화면만 만져 볼 때 씁니다.

스크립트:

```bash
# 사장님 블로그 글을 가져와 말투 예시로 만들기 (private/ 아래에 저장, git에 올라가지 않음)
npx tsx scripts/import-blog.ts --blog <blogId> --footer-start "<꼬리말 첫 줄>"

# 실제 글 하나를 메모로만 다시 써 보게 해서 사장님이 쓴 글과 비교 (API 키 필요, 약 $0.1)
ANTHROPIC_API_KEY=... npx tsx scripts/backtest.ts --logNo <id>
```

배포 순서와 첫 실제 확인: [docs/deploy-checklist.md](docs/deploy-checklist.md)
