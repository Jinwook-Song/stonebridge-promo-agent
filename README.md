# 스톤브릿지 홍보글 에이전트

동네 카페 **스톤브릿지** 사장님이 사진 몇 장과 한 줄 메모를 올리면, 사장님 말투로 **네이버 블로그 · 인스타그램 · 당근 · 네이버 플레이스** 글 초안을 한 번에 만들어 주고, 케이터링 문의를 붙여 넣으면 가격표로 **견적서(엑셀)와 회신 메일**을 만들어 주는 에이전트입니다.
실제 동작 주소: https://stonebridge-promo.pages.dev (사장님 전용, 비밀번호 로그인)
노마드코더 AX School "Put AI to Work" 챌린지 과제로 만들고 있습니다.

## 누구를 위한, 어떤 업무인가

- **클라이언트:** 구리시에서 카페 스톤브릿지를 운영하는 사장님 (지인, 실제 클라이언트). 알바생 4명과 매장을 운영하고, 케이터링 사업 "스톤테이블"을 새로 시작했습니다.
- **대신하는 업무:** 홍보글 쓰기. 사장님은 한 달에 1~2번, 같은 내용을 네 채널에 말투만 바꿔 직접 올립니다. 블로그 글 하나에 1~2시간이 걸리고, 사진 고르기가 가장 오래 걸립니다.
- **대신하는 업무 2:** 케이터링(스톤테이블) 견적. 엑셀 작성 자체는 약 20분이지만, 한 건에 1~6시간이 걸리는 건 **다른 업체가 어디에 무슨 메뉴를 얼마에 냈는지 찾아보는 일**입니다. 가격표도 따로 없습니다.
- **왜 이 업무인가:** 사장님 인터뷰에서 "업무 하나가 사라진다면?"과 "미루게 되는 일은?" 두 질문에 모두 **"글 쓰는 거"**라고 답했습니다. 예전에 ChatGPT·Claude로 써 봤지만 **말투가 AI 같아서** 쓰지 않게 됐습니다.

> 처음 기획안(Day 1)은 케이터링 견적 에이전트였습니다. 이후 사장님과 업무 전체를 인터뷰해 보니 견적보다 홍보글이 훨씬 급하고 자주 하는 일이라 대상을 바꿨습니다. 그래서 홍보글을 먼저 만들고(11/08), 견적 에이전트를 이어서 만들었습니다(11/09).

## 어떻게 동작하나

1. 사장님이 휴대폰으로 웹 화면을 열고, 비밀번호로 들어가 사진(최대 40장)과 메모를 올립니다. 'AI로 고르기'를 누르면 AI가 글에 넣을 사진 8장 이하를 블로그 순서대로 골라 주고, 사장님이 탭해서 바꿉니다. (예: "구리 관공서 마카롱 8구 70세트 단체 주문")
2. 에이전트(Claude Opus 5.5)가 사장님이 직접 쓴 블로그 글과 이미 확정한 글을 말투 예시로 삼아, 블로그·인스타·당근·플레이스 초안을 한 번에 만듭니다. 약 30초~1분이 걸리고, 화면을 닫아도 계속 만듭니다.
3. 가격표, 배송 정책, 주소·영업시간 꼬리말은 AI가 쓰지 않고 **설정 화면에 저장해 둔 문구를 코드가 그대로 붙입니다.** 틀린 가격이 나갈 수 없게 하려는 것입니다.
4. 사장님이 채널별로 고치고(자동 저장), **복사 버튼**으로 각 채널에 올립니다. 마음에 안 들면 한 줄 지시("좀 더 짧게")로 그 채널만 다시 쓰게 합니다.
5. 마음에 들면 **확정**합니다. 확정한 글은 다음 글의 말투 예시가 됩니다.

견적은 이렇게 동작합니다.

1. 통화 메모나 문의 메일을 붙여 넣으면 Claude가 날짜·장소·인원·원하는 메뉴를 뽑습니다.
2. 줄마다 가격은 AI가 정하지 않고 **사장님 가격 기준표에서 코드가 계산**합니다. 기준표에 없는 메뉴는 빈칸으로 두고 사장님이 넣습니다.
3. 옆 비교 칸에 경쟁 업체 블로그·가격 페이지에서 미리 모아 둔 비슷한 행사와 공개 가격을 출처 링크와 함께 보여 줍니다.
4. 회신 메일 초안과 엑셀 견적서를 만들고, 수정 요청이 오면 v2·v3를 만들되 사장님이 손으로 바꾼 가격·서비스는 그대로 둡니다.

사장님이 쓰는 에이전트는 Cloudflare Workers에서 항상 켜져 있는 웹 프로그램이고, Claude API를 호출합니다. 휴대폰에서 빠르게 열리도록 서울 가까운 Cloudflare Pages 앞단을 두었습니다(화면 응답 1~10초 → 0.1~0.5초).

## 진행 상황

### 지금 되는 것
- 휴대폰 웹에서 사진(0~8장) + 메모 → 블로그·인스타·당근·플레이스 초안을 한 번에 (Claude Opus 5.5, 약 30초~1분, 회당 약 $0.1)
- 사진 자동 고르기: 최대 40장을 올리면 AI가 메모 내용이 잘 보이는 사진 8장 이하를 고르고 순서와 한 줄 이유를 붙임 (작은 미리보기만 AI에 보냄, 27장 기준 약 7초 · 약 $0.05). 사장님은 탭으로 넣고 빼기
- 채널별 고치기(자동 저장), 복사, 다시 쓰기(한 줄 지시), 확정
- 꼬리말·가격표는 AI가 아니라 코드가 붙임
- 메모에 없는 숫자("세 세트" 같은 한글 숫자 포함)와 (개인 고객 주문이면) 이름은 노란색으로 표시하고, 메모에 없는 주문 방법·예약·할인 같은 운영 방식은 쓰지 않게 함 (지어내기 방지)
- 확정한 글이 다음 글의 말투 예시가 됨
- 카톡 알림: 초안이 다 만들어지면 "초안이 준비됐어요" 알림(기본 켜짐), 매일 23:20 발주 알림, 고른 날짜에 "이번 달 홍보글" 알림을 카카오 "나에게 보내기"로 보냄 (설정에서 켜고 끄기, 비즈 앱·권한 신청 없이 동작 확인). 설정 순서: [docs/kakao-setup.md](docs/kakao-setup.md). **사장님 휴대폰 카톡에 연결됨(11/09)**, 첫 23:20 발주 알림 실제 발송 확인
- 사장님 블로그 글 50개를 말투 예시로 사용 (글 원문은 저장소에 넣지 않음)
- 화면을 닫아도 생성이 계속됨 (Cloudflare Workflows)
- 사진은 서명된 10분짜리 주소로만 AI에 전달
- 사장님 인터뷰 (업무 25개 체크, 질문 47개 답변) 와 설계 문서: [docs/superpowers/specs/2026-11-08-promo-agent-design.md](docs/superpowers/specs/2026-11-08-promo-agent-design.md)
- 케이터링 견적 (스톤테이블): 손님 문의를 붙여 넣으면 가격표(설정에서 관리)를 바탕으로 견적 줄을 만들고, "인원 150명으로" 같은 수정 요청으로 새 버전을 만듭니다. 합계와 부가세는 코드가 계산하고, 엑셀(수식 포함)로 내려받습니다.
- 경쟁 업체 감시: 사장님이 정한 블로그 글과 가격 페이지를 매일 새벽에 읽어 소식과 가격을 쌓고(한 번 돌 때 Claude 호출은 최대 30번), 견적을 만들 때 비교 칸에 출처 링크와 함께 보여 줍니다. 감시 목록은 앱에서 고치고 "지금 한 번 돌리기"로 바로 돌릴 수 있습니다. 지금 업체 14곳(블로그 12개·가격 페이지 8개), 행사 50건·가격 66건 (11/10).
- 사장님께 묻기: 만들다 생기는 "사장님만 아는 것"(실제 가격, 사례 글에 쓸 사실, 업체 관계)을 앱의 `/questions` 페이지에 올리면, 글 목록 위에 "확인할 것 N개"가 뜨고 사장님이 맞아요·나중에·모르겠어요 또는 직접 적어서 답합니다. "맞아요"를 누르면 꼬리말 같은 설정은 바로 반영됩니다. 처음 연 날 11개 중 7개에 약 20분 만에 답했습니다(11/09).
- 테스트 601개 (vitest, Cloudflare Workers 런타임)

### 아직 안 되는 것
- 사장님 실사용: 홍보글·견적 모두 사장님이 직접 써 본 피드백을 아직 받지 못했습니다(실제 견적 0건).
- 가격 기준표: 예전 견적서에서 뽑은 7개 항목이 아직 "확인 필요" 상태입니다. 사장님이 확인해야 견적 가격을 믿을 수 있습니다.
- 경쟁 업체 일부: 봇 확인 페이지를 띄우는 사이트, 단가 없이 최소 주문 금액만 있는 페이지, 인스타그램·숨고는 읽지 못합니다(블로그만 봅니다).
- 자동 게시: 네이버 블로그·당근·플레이스는 공식 글쓰기 API가 없어 **복사 버튼**으로 올립니다. 인스타그램은 공식 API가 있어 다음 버전 후보입니다.
- 스톤테이블(케이터링) 브랜드 분리: 지금은 스톤브릿지 한 가게 기준입니다.

## 개발

스택: React Router 8 + Cloudflare Workers (Workflows, D1, R2) + Drizzle + Claude API (`@anthropic-ai/sdk`).

```bash
# Node 22.22 이상 필요
npm install
cp .dev.vars.example .dev.vars   # 값을 채웁니다
npm run dev                      # http://localhost:5173
npm test                         # vitest
```

`.dev.vars`에 들어가는 이름 (값은 저장소에 넣지 않고, 배포 때는 `wrangler secret put`으로 Cloudflare secret에 넣습니다):

- `ANTHROPIC_API_KEY`
- `SESSION_SECRET`
- `OWNER_INITIAL_PASSWORD`
- `IMAGE_URL_SECRET`
- `PUBLIC_ORIGIN` (로컬은 `http://localhost:5173`)
- `FAKE_CLAUDE=1` (선택): Claude를 부르지 않고 가짜 초안을 돌려줍니다. API 키 없이 화면만 만져 볼 때 씁니다.

스크립트:

```bash
# 사장님 블로그 글을 가져와 말투 예시로 만들기 (private/ 아래에 저장, git에 올라가지 않음)
npx tsx scripts/import-blog.ts --blog <blogId> --footer-start "<꼬리말 첫 줄>"

# 실제 글 하나를 메모로만 다시 써 보게 해서 사장님이 쓴 글과 비교 (API 키 필요, 약 $0.1)
ANTHROPIC_API_KEY=... npx tsx scripts/backtest.ts --logNo <id>
```

배포 순서와 첫 실제 확인: [docs/deploy-checklist.md](docs/deploy-checklist.md)
